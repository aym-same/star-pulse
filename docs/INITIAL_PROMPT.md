# 最初の指示文

2026年9月6日、[Smart Glasses Vibeathon Kagoshima 2026｜XR Meetup Kagoshima 3周年記念イベント](https://luma.com/zudko7vk)で、Codex GPT-6 Astraに送った最初の指示です。制作時の会話記録から、ユーザーが入力した本文をそのまま掲載しています。

```text
Rokid Glasses で体験できるアプリを、10分で作成して！

いま有線の開発者ケーブルで、Rokid Glasses 本体で接続しています。
何かしらのゲームがいいな。
操作はタップするだけ、複雑な操作を体験者にさせないように。
効果音もしっかりいれたいな。

Astraを全体ディレクションにして、実行はLuna MAXのサブエージェントに任せるようにしてください。
```

この指示には、ゲームのタイトルや具体的なルールは書かれていません。「タップだけ」「効果音を入れる」という条件とAIの役割分担を伝え、STAR PULSEというゲームの形はAI側から提案・実装されました。

会話記録では、この依頼からゲームの完成報告まで、ユーザーからの追加の修正指示はありません。完成後のやり取りは、制作プロセス・技術構成・遊び方の紹介画像の作成依頼と、実機デバッグを行ったかの確認です。

「10分」は指示に含めた制作時間の条件です。当時は有線接続したRokid Glassesと開発環境を用意した状態で依頼しています。

現在の公開版では、ゲームのJava・Androidリソースを保持し、公開用のビルド手順と文書を整えています。今回の確認範囲は[検証状況](VERIFICATION.md)、制作背景は[README](../README.md#制作と公開)を参照してください。
